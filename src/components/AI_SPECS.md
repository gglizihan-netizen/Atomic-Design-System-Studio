## 🎨 为什么需要“AI 契约设计系统协议”？
在过去，产品经理和 UI 主题专家的最大痛点是**“AI 绘图虽好看，但还原成前端界面时就像开盲盒，每次样式都不一致！”** 
即使大模型能够写出 React 代码，但它生成的往往是带有个性斑驳、带有野生 CSS/Tailwind 类的“一次性破坏性代码”。一旦切换暗色模式、或是更换字体和间距规则，AI 写好的页面瞬间崩溃。

**Atomix UI 深度打破了这一魔咒！** 我们将设计系统抽离为严格的、自下向上滋养的 **五层结构协议**：

```
+--------------------------------------------------------+
|  Layer 5: AI 声明式逻辑运行时 (Declarative Runtime)      | <-- AI 只输出 JSON Schema 协议，动态瞬时渲染
+--------------------------------------------------------+
|  Layer 4: 场景模拟拼接 (Scenario Realizations)          | <-- 基于 Primitive 插拔的计算节点部署表单
+--------------------------------------------------------+
|  Layer 2 & 3: 受约原子原语与组合 (Primitive Registry)   | <-- Button, Input, Dropdown, Modal (无污染)
+--------------------------------------------------------+
|  Layer 1.5: 跨次元行为令牌 (Behavior Tokens)            | <-- 决定聚焦光环、防误触拦截、物理弹性动效
+--------------------------------------------------------+
|  Layer 1: 静态视觉主题令牌 (Design Tokens Base)          | <-- 决定色彩偏向、品牌字体、间距大小、圆角
+--------------------------------------------------------+
```

## 📖 第一部分：五层协议透视（从配方到成品）

### 💡 Layer 1 & 1.5：设计系统的“灵魂中枢（Design & Behavior Tokens）”
*   **Layer 1 (静态视觉令牌)**：
    *   **颜色 (Colors)**：不仅规定主品牌色 `brand`，还分级出文本色 `textPrimary`（深碳黑）、`textMuted`（辅助灰）、背景输入色 `bgInput`。切换颜色，全系统瞬间焕新。
    *   **字重与大小 (Typography)**：配置 `sizeSm` / `sizeBase` / `sizeLg`，并且将页面主标题与数字等宽字体全权解耦。
    *   **边界与投影 (Borders & Shadows)**：控制组件圆角 `radiusMd`（经典圆）或 `radiusFull`（全胶囊圆）。
*   **Layer 1.5 (动态行为令牌 —— Atomix UI 的最大特色)**：
    *   我们将“交互体验”也写成了数据令牌！
    *   *案例 A (`buttonPressScale`)*：点击按钮时，按钮收缩多深？软萌糖果主题收缩到 `0.93`，理性现代收缩到 `0.97`。
    *   *案例 B (`motionCurve`)*：组件滑开的曲线。是可爱的带有物理回弹的弹性曲线 (`spring`)？还是干净干练的急速线性 (`rigid`)？
    *   *案例 C (`modalDismissOverlay`)*：**高危行为锁**。如果为 `false`，当弹窗打开时，用户点击黑屏背景是绝对无法退出的，必须手动点击 [取消/确定] 按钮。**杜绝破坏性失误！**

### 📦 Layer 2 & 3：受控的标准原子原语（Primitives Library）
在我们的 `src/components/atoms/` 下，共开箱即用维护了 7 款大核心原子原语。它们在头部写满了保姆级别的简体中文注释：
1.  **Button (按钮)**：支持 loading 阻断状态校验，并融合品牌阻尼及按下自嗨微比例缩放。
2.  **Input (单行文本输入器)**：内置 error 警告高亮变色与状态防御。
3.  **Dropdown (下拉单/复选器)**：支持内置即时模糊搜索机制、各选项二级说明文字。提供单选高亮与多选 Removable Tags (可移除芯片胶囊) 结合圆角描边/填充复选框 (Checkbox) 的高级视觉反馈。
4.  **Modal (安全防御弹窗)**：强制执行 `modalDismissOverlay` 拦截规则，阻隔误触，安全防滚动穿透。
5.  **Navbar (置顶导航栏)**：对齐 12 列对称黄金响应式网格布局，内置高光呼吸条状态感应定位。
6.  **Icon (智能语义图标)**：封装 Lucide 主流图符体系，提供无缝语义色变分流以及自旋加载微交互。
7.  **Breadcrumb (智能面包屑)**：支持超长纵深智能 Ellipsis 折叠、一键平滑平铺展开、支持自定义物理分隔符及字体字重自适应。

### 🚀 Layer 5：AI-Native 声明式运行时解析流程 (Playground)
这是我们证明“设计一贯性”的核武器。**AI 在为用户拼装新界面时，不再输出破坏式的 HTML 或 CSS，它只做以下极简动作**：
1.  **读取大意图**：用户呼唤：“生成一个用户登录和提交卡片”。
2.  **严格遵循 `AI_MANIFEST.json` 规范**：AI 组织出一份符合受约束 Schema 的 JSON 数据：（例如 `type: "FormCard", children: [ ... ]`）。
3.  **送入运行时中继器 (Runtime Renderer)**：我们内置的解析器（位于 `ScenarioSandbox.tsx` 中）拦截该 JSON 数据，瞬间实例化出真实的 React 与 Tailwind 原语，完美贴合全局令牌性格！

## 🛠️ 第二部分：AI 应该如何在本项目中自洽开发？（給 AI 乃至后续开发者的锦囊）

如果后续你引入了更高级的 AI 组件 Agent，请将以下准则输入它的 System Prompt：

```
[AI 运行指令约束：]
1. 绝对不要尝试在组件里编写硬编码的内联颜色或背景色 (如 style={{ background: '#F1F5F9' }})，也绝不可以在 class 中混入未经过令牌包装的硬编码色值。
2. 每一个色彩展现、动画过渡时长、圆角和阴影，必须去读取 `tokens` 上下文变量 (如 tokens.colors.brand)。
3. 【关键警示：勿因对齐微调而硬编码】当 AI 需要让组件在特定的视觉(如 Hover、Selected 态)完美对齐截图时，很容易因为 Token 中没有特定细分 Slot (例如：bgSelection 选中态底色) 而图省事硬编码 16 进制颜色。这是破坏系统主题换肤契约的死罪！
   - 正确解法：必须先去修改 `/src/types/tokens.ts` 下的 `ColorSet` 添加你需要的语义 Slot，然后在 `/src/constants/presets.ts` 把四个预设主题全部补齐，最后在组件中引用这个新添加的 `tokens.colors.xxx` 属性值。
4. 组件的动画不要乱用第三方不合规的动画库。我们已经统一安装并封装了 `motion/react`。
5. 在编写 TS 类型定义时，所有 import 都必须写在文档最顶部（Named Imports），绝不可以使用 import type 来指向枚举类型（enum）。
6. 组件少用生硬的 border 边框线隔断。在亮色背景下多使用淡雅的色彩阶梯（例如 tokens.colors.bgPage 垫住 cards 表层，通过颜色区隔卡片，高级感满分）。
```

## 💎 第三部分：项目文件结构指津（PM 友好说明）
为了方便你学习完备的前端工程化开发，这里额外附赠整个项目顶层配置元文件的通俗白话解说：

*   **`.env.example`**：
    “空的佐料配方宣示书”。里面写着我们驱动 AI 需要的 `GEMINI_API_KEY` 名额，但把真实密码空出来。这能避免你把公司私人密码传上网络，造成无可挽回的账单损失。
*   **`.gitignore`**：
    “Git 视线防守网”。告诉我们代码版本发布中，哪些东西是不该上传、应该装作看不见的（例如高达数十万文件的本地依赖包 `node_modules` 文件夹，以及临时编辑日志）。
*   **`index.html`**：
    “全家桶大毛坯底盘”。整个单页面应用 React 渲染挂载的唯一的也是最尊贵的物理节点 `<div id="root"></div>` 回归地。
*   **`vite.config.ts`**：
    “极速编译梦工厂发电机”。在这里配置了把 React 组件、Tailwind 原子类以及 TS 文件高速编译成极速轻量浏览产物的全部中继器。
*   **`src/components/AI_MANIFEST.json`**：
    “大模型受控组件索引契约”。这个正是你需要的“模型调用描述文件”。AI 或开发者，只需要严格遵循该 JSON 属性范围拼装面板，就能保持一辈子的一致调性！
